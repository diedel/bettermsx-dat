# BetterMSX ROMs Database - Logiqx DAT File

This is a Logiqx DAT format conversion of the MSX ROM Database, compatible with ROM management tools such as ROMVault, ClrMamePro, Igir, and RomCenter.

## Data Source

This DAT file is derived from the **MSX ROM Database** maintained at [romdb.vampier.net](https://romdb.vampier.net/).

- **Original Database**: https://romdb.vampier.net/
- **Source File**: https://romdb.vampier.net/Archive/json-msxromsdb.zip
- **Format Conversion**: JSON to Logiqx DAT XML

All credit for the ROM identification data, SHA1 hashes, and metadata goes to the MSX ROM Database project and its contributors.

## Download

**Latest DAT file**: [msxromsdb.dat](https://raw.githubusercontent.com/diedel/bettermsx-dat/refs/heads/main/msxromsdb.dat)

## Usage

Import the DAT file into your ROM management tool (ROMVault, ClrMamePro, Igir, etc.) to verify and organize your MSX ROM collection.

**Note**: This DAT file contains only hash identification data. No ROMs are included or distributed.

This is an unofficial, community-created derivative work. If the maintainers of the MSX ROM Database have any concerns about this conversion, please contact me and I will gladly take it down or modify it as requested.
